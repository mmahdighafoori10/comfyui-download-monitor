# اپ پایش دانلود مدل‌های ComfyUI

این اپ وضعیت دانلود مدل‌های ComfyUI را مستقیم از فایل‌های محلی خود ComfyUI می‌خواند. برای نمایش درصد و نوار پیشرفت، هیچ درخواست هوش مصنوعی یا اتصال اینترنتی جداگانه‌ای ایجاد نمی‌شود؛ بنابراین پایش آن توکن مصرف نمی‌کند.

[![Latest release](https://img.shields.io/github/v/release/mmahdighafoori10/comfyui-download-monitor?label=download&logo=github)](https://github.com/mmahdighafoori10/comfyui-download-monitor/releases/latest)

## نصب سریع از ترمینال

در Windows PowerShell اجرا کنید:

```powershell
irm https://raw.githubusercontent.com/mmahdighafoori10/comfyui-download-monitor/main/install.ps1 | iex
```

اسکریپت نصب آخرین Setup را از GitHub Releases می‌گیرد، SHA-256 آن را بررسی می‌کند و برنامه را برای همان کاربر نصب می‌کند. اگر .NET Framework 4.8 روی ویندوز موجود نباشد، نصب‌کننده رسمی Microsoft به‌صورت خودکار دریافت و اجرا می‌شود.

برای دریافت مستقیم فایل ویندوزی نیز از [آخرین Release](https://github.com/mmahdighafoori10/comfyui-download-monitor/releases/latest/download/ComfyUIDownloadMonitorSetup.exe) استفاده کنید.

## چه کارهایی انجام می‌دهد؟

- وضعیت همه دانلودها را هر یک ثانیه تازه می‌کند.
- درصد پیشرفت، حجم دریافت‌شده، حجم کل، سرعت تقریبی و زمان باقی‌مانده را نشان می‌دهد.
- دانلودهای کامل، فعال، ناموفق و لغوشده را از هم جدا می‌کند.
- با شروع یک دانلود معتبر و تازه، پنجره پایش را خودکار باز می‌کند.
- جلوی باز شدن چند نسخه هم‌زمان از اپ و نگهبان را می‌گیرد.
- خطای دانلود را داخل کارت همان مدل نمایش می‌دهد.

## کنترل دانلودها

برای هر دانلود فعال این دکمه‌ها در دسترس‌اند:

- **مکث:** پردازش همان دانلود را موقتاً نگه می‌دارد.
- **ادامه:** دانلود مکث‌شده را از همان نقطه ادامه می‌دهد.
- **لغو دانلود:** پس از گرفتن تأیید، درخواست لغو را به ComfyUI می‌فرستد. فایل نیمه‌دانلودشده پاک می‌شود و دانلود بعدی از ابتدا شروع خواهد شد.
- **مکث همه / ادامه همه:** همه دانلودهای فعال را یک‌جا کنترل می‌کند.
- **تازه‌سازی:** وضعیت روی صفحه را همان لحظه دوباره می‌خواند.

اپ پیش از مکث یا ادامه، شناسه پردازش و زمان شروع آن را بررسی می‌کند تا فرمان اشتباهی روی پردازش دیگری اجرا نشود. اگر پنجره را ببندید، دانلودهایی که از داخل همین اپ مکث شده‌اند خودکار ادامه پیدا می‌کنند.

## پایش خودکار

فایل `ComfyDownloadWatcher.ps1` یک نگهبان سبک و محلی است. این نگهبان پوشه وضعیت دانلودهای ComfyUI را بررسی می‌کند و فقط وقتی یک دانلود واقعی با شناسه تازه شروع شده باشد، پنجره اپ را باز می‌کند.

نگهبان:

- از مدل هوش مصنوعی استفاده نمی‌کند؛
- داده‌ای به اینترنت نمی‌فرستد؛
- فقط فایل‌های `JSON` محلی و پردازش دانلود مربوط به آن‌ها را بررسی می‌کند؛
- در هر لحظه تنها یک نسخه از خودش اجرا می‌کند.

## اجرای اپ

### نسخه نصب‌شده ویندوز

فایل `ComfyUIDownloadMonitorSetup.exe` نصب‌کننده مستقل ویندوز است. این Setup:

- اپ را بدون نیاز به دسترسی Administrator در پوشه کاربری نصب می‌کند؛
- میان‌برهای Desktop و Start Menu می‌سازد؛
- نگهبان دانلود را به Startup ویندوز اضافه می‌کند؛
- برنامه را در Settings > Apps برای حذف استاندارد ثبت می‌کند.

پس از نصب، میان‌بر `ComfyUI Download Monitor` را اجرا کنید. نگهبان همیشه سبک و مخفی می‌ماند و فقط با شروع دانلود واقعی، پنجره مدیر دانلود را باز می‌کند.

### اجرای مستقیم از سورس

برای اجرای دستی، فایل زیر را باز کنید:

`Open-Comfy-Download-Monitor.cmd`

این فایل هم نگهبان محلی را فعال می‌کند و هم پنجره پایش را باز می‌کند.

برای فعال‌شدن نگهبان پس از ورود به ویندوز، فایل زیر را فقط یک‌بار اجرا کنید:

`Install-AutoStart.cmd`

## فایل‌های اپ

| فایل | کاربرد |
|---|---|
| `ComfyDownloadMonitor.ps1` | رابط اصلی، نوارهای پیشرفت و کنترل مکث، ادامه و لغو |
| `ComfyDownloadWatcher.ps1` | تشخیص خودکار شروع دانلود و باز کردن پنجره |
| `ComfyResumeWorker.ps1` | ادامه امن فایل نیمه‌کاره با HTTP Range و retry تصاعدی |
| `Open-Comfy-Download-Monitor.cmd` | اجرای دستی اپ و نگهبان |
| `Start-Comfy-Download-Watcher.cmd` | اجرای نگهبان بدون باز کردن دستی پنجره |
| `Install-AutoStart.ps1` | ساخت تنظیم اجرای خودکار هنگام ورود به ویندوز |
| `Install-AutoStart.cmd` | اجرای ساده نصب خودکار |
| `install.ps1` | نصب آخرین Release از ترمینال همراه با بررسی پیش‌نیاز و SHA-256 |
| `build/Launcher.cs` | لانچر ویندوزی EXE برای مانیتور و نگهبان |
| `build/Setup.cs` | نصب و حذف کاربرمحور برنامه در ویندوز |
| `Build-WindowsApp.ps1` | ساخت لانچر و Setup در پوشه `dist` |
| `.github/workflows/release.yml` | ساخت و انتشار خودکار Setup با ایجاد تگ نسخه |

## ادامه امن بعد از قطع یا ری‌استارت

- دانلود اصلی از مانیتور جداست؛ بستن یا اجرای دوباره پنجره دانلود را متوقف نمی‌کند.
- فایل در یک مسیر موقت کنار مدل نوشته می‌شود و فقط پس از کامل‌شدن به نام نهایی منتقل می‌شود؛ بنابراین ComfyUI فایل ناقص را به‌عنوان مدل بارگذاری نمی‌کند.
- اگر سرور از HTTP Range پشتیبانی کند، ادامه از آخرین بایت ذخیره‌شده انجام می‌شود.
- در قطع شبکه، فایل موقت حذف نمی‌شود و retry با فاصله افزایشی انجام می‌شود.
- اگر ویندوز یا پردازش وسط دانلود خاموش شود، نگهبان بعد از ورود دوباره دانلود رهاشده را بازیابی می‌کند.
- برای خطاهای پایان‌یافته، دکمه `ادامه / تلاش مجدد` در کارت دانلود موجود است.

## ساخت نسخه ویندوز

در PowerShell اجرا کنید:

```powershell
.\Build-WindowsApp.ps1
```

فایل‌های `ComfyUIDownloadMonitor.exe` و `ComfyUIDownloadMonitorSetup.exe` در پوشه `dist` ساخته می‌شوند. فرایند ساخت آفلاین است و از کامپایلر داخلی .NET Framework ویندوز استفاده می‌کند.

## وضعیت‌هایی که نمایش داده می‌شوند

| وضعیت | معنی |
|---|---|
| در حال شروع | ComfyUI پردازش دانلود را آماده می‌کند. |
| در حال دانلود | داده‌های مدل در حال دریافت است. |
| مکث شده | پردازش دانلود موقتاً نگه داشته شده است. |
| کامل شده | فایل نهایی با حجم کامل در پوشه مدل قرار دارد. |
| خطا | دانلود ناموفق بوده و متن خطا نمایش داده می‌شود. |
| متوقف شده | دانلود با درخواست لغو متوقف شده است. |

## محدوده عملکرد

اپ دانلودهایی را پایش می‌کند که وضعیتشان در پوشه `.comfy-downloads` ثبت شده باشد. دانلودهای دستی مرورگر که خارج از ComfyUI انجام می‌شوند در این صفحه دیده نمی‌شوند.
